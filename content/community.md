팀 과제

# 프로젝트 목적
학습한 네트워크와 linux 내용을 활용하여 하나의 회사 인프라 직접 설계하고 구축한다.
현재까지 배운 내용을 정확하게 연결하여 하나의 환경을 완성하는 것이 목표이다.

네트워크 설계 -> IP 주소 설계 -> Router 설정 -> NAT 설정 -> Linux 서버 구축 -> 계정/그룹/권한설정 -> Disk/Mount 설정 -> 서비스 구축 -> 전체 통신 테스트
